# shadcn/ui primitives (new-york)

Copied verbatim from
[github.com/paperclipai/paperclip](https://github.com/paperclipai/paperclip) (MIT,
Copyright (c) 2025 Paperclip AI), `ui/src/components/ui/`, which are themselves stock
[shadcn/ui](https://ui.shadcn.com) components (MIT) in the *new-york* style.

They were taken from Paperclip rather than re-generated by the `shadcn` CLI for one
reason: staple's theme *is* Paperclip's token sheet (see
`../../styles/paperclip-tokens.css`), and these are the components that sheet was tuned
against. Generating fresh ones would mean two independently drifting copies of the same
design system.

Every file here is imported by the app. If a future ticket needs another primitive
(`tooltip`, `badge`, `dropdown-menu`, …), copy it from the same Paperclip directory
rather than generating it, for the drift reason above.

Treat these as vendored: if one needs a behaviour change, prefer wrapping it in
`../` over editing it here, so the next `shadcn` update stays a clean diff.
