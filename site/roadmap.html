Roadmap

What works now. What comes next.

The proof of concept already covers the complete local agent loop. The next milestones make that model easier to share and connect without weakening its local-first rules.

M0

Core spike

SQLite task model, create/list/checkout/update/comment operations, and an MCP server used by a real agent session.

shipped
M1

Reliable local coordination

CLI, dependency cycles and wake events, revisioned documents, duplicate guards, idempotency keys, workspace registry, unique identifiers, and cross-workspace links.

shipped
M1.5

Local visual workspace

Inbox, terminal board, web board, tree, issue detail, comments, documents, and a dependency graph in single-workspace and hub modes.

shipped
M1.6

Portable reports

Export a static task snapshot for reviews, archives, and handoffs without running the local server.

next
M2

GitHub Issues adapter

Add task links, field ownership, an outbox, and reconciliation so teams can connect local agent work to GitHub without making GitHub the execution database.

planned
M3

ClickUp adapter

Map statuses per list and project dependency relations while keeping Staple's local task rules intact.

planned
Later

Editor and shared-service options

Explore a VS Code sidebar and an optional HTTP mode for teams that need multiple machines to write to one workspace.
