# Budget and estimates

This page explains how to estimate work, see how long it really took, and keep
an eye on your provider usage limits.

## What this page will cover

- Setting an estimate and reading it against the agent's actual work time.
- Forecasts for an epic or a milestone.
- Recording provider usage limits, and what the budget view shows.

Until this page is written, the [CLI reference](cli.md#estimates-vs-actuals) and
the [web UI tour](web-ui.md#estimates) cover the commands and the views.
