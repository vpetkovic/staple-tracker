# Errors and exit codes

This page lists the errors staple returns, the exit code each one sets, and
what to do about each.

- Every error code the CLI and the MCP server return.
- The exit code for each, for scripts.
- The usual cause and the fix.

Until this page is written, the [CLI reference](cli.md#exit-codes) lists the
exit codes.
