# Approval gates

This page explains how to make a ticket wait for a person's approval, and how
you approve it or ask for changes.

## What this page will cover

- When to put a gate on a ticket.
- What an agent sees while its ticket waits for approval.
- Approving, requesting changes, and where gated work shows up in the inbox and the web UI.

Until this page is written, the [CLI reference](cli.md#approval-gates) covers the
gate commands.
