# Plans become tickets

This page shows how an implementation plan becomes an epic with tickets that
agents work through.

## What this page will cover

- Breaking a plan into an epic, its tasks and the dependencies between them.
- Keeping the plan on the ticket as a document, instead of a Markdown file in the repository.
- Filing new work under the same epic when it turns up mid-flight.
- Reading progress: what is done, what is ready, what waits on what.

Until this page is written, [How an agent works a ticket](working-a-ticket.md)
covers the loop an agent follows on each ticket.
